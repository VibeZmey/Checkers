
# Checkers (Шашки) — Qt C++ реализация
Репозиторий: @VibeZmey/Checkers

Краткое описание
----------------
Это реализация классической игры в шашки, написанная на C++ с использованием фреймворка Qt (Widgets). Проект содержит игровую логику, GUI на Qt, ресурсы (иконки/спрайты), и набор тестов (Qt Test) для проверки игровой логики.

Я подготовил этот README специально под Qt C++ проект — ниже приведены точные инструкции по сборке, запуску и вкладу.

Требования
---------
- Qt 5.15+ или Qt 6.x (рекомендуется последняя LTS-версия, с которой вы работаете)
- Компилятор с поддержкой C++17 (GCC/Clang/MSVC)
- CMake >= 3.16 (если проект использует CMake) или qmake (если есть .pro)
- Необязательно: Qt Creator для удобной разработки и отладки

Игровые правила
---------------
Реализованы стандартные правила (уточните конкретную вариацию в коде или docs/rules.md):
- Передвижение по диагонали.
- Взятие обязательно.
- Превращение в дамку при достижении крайней линии.
- Последовательные взятия.
